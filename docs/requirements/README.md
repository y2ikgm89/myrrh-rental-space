## 要件定義の書き方

各要件書は以下の構成で記載：

1. **概要**: 機能の目的と範囲
2. **機能要件**: 具体的な動作仕様
3. **非機能要件**: パフォーマンス、セキュリティ等
4. **データモデル**: Prismaスキーマ
5. **実装状況**: チェックリスト
