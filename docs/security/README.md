## セキュリティ原則

### 1. 多層防御

```
[Cloudflare] → [Cloud Run] → [アプリケーション] → [データベース]
     ↓              ↓              ↓                ↓
   DDoS保護    タイムアウト    レート制限       暗号化
```

### 2. 入力は信用しない

- すべての入力をZodでバリデーション
- サーバーサイドで必ず検証
- SQLインジェクション対策（Prisma）
- XSS対策（DOMPurify）

### 3. 最小権限の原則

- 認証必須（withAuth / verifySession）
- ロールベースアクセス制御（RBAC）
- 環境変数で秘匿情報管理

## クイックチェックリスト

### Server Actions

- [ ] `withAuth()` で認証ラップ
- [ ] Zodスキーマでバリデーション
- [ ] エラーメッセージに内部情報を含めない

### データ保存

- [ ] APIキー/シークレットは暗号化（AES-256-GCM）
- [ ] パスワードはハッシュ化
- [ ] 機密データはログに出力しない

### フロントエンド

- [ ] ユーザー入力のサニタイズ
- [ ] CSRFトークン検証
- [ ] セキュリティヘッダー設定
