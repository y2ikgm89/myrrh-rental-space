# ページ編集ワークスペース刷新

## 目的

ページ管理 UI を「フォーム群の並び」から「構成・キャンバス・インスペクタを同時に扱う編集ワークスペース」へ作り直す。

## 現状の問題

- 編集画面が `SectionList + SectionEditor + 狭い iframe` の派生形に留まり、プレビューが脇役になっている
- プレビュー列が固定幅のため、本番と異なる viewport で判断しやすい
- ページ設定 / ヒーロー / セクション編集が分断され、画面の主役が曖昧
- ページ編集が「公開画面を作る体験」ではなく「管理フォームを埋める体験」になっている

## 新しい情報設計

- `navigator`: セクション構成と並び替え
- `canvas`: 本番ルート相当のプレビュー、viewport 切り替え、集中モード
- `inspector`: 選択中セクション編集、ページ設定、ホーム専用ヒーロー設定

## ビジュアル方針

- visual thesis: 工具感のある管理画面ではなく、静かな編集スタジオとして見せる
- content plan: 構造選択 → 実幅プレビュー → 属性編集
- interaction thesis:
  - パネルを閉じて canvas を主役にできる
  - viewport を即時切り替えられる
  - 管理画面 chrome を隠して集中モードへ入れる

## 実装スライス

1. 既存の `SectionMasterDetail` を廃止し、3 面ワークスペースに差し替える
2. `PageLivePreview` を中央キャンバスへ再設計し、viewport プリセットを持たせる
3. inspector 内に `section / hero / page` を再配置する
4. モバイルでは `canvas / navigator / inspector` の3ビューに切り替える

## 今回の非対象

- プレビュー上クリックでセクションを選択する visual editing
- 未保存 draft を iframe に即時反映するライブ同期
- セクションフォーム自体の全面リデザイン
