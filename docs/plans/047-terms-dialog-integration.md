# Plan 047: 利用規約ダイアログ統合

## 概要

予約フォームの利用規約・プライバシーポリシー同意UIを改善。
リンクをクリックするとダイアログでプレビュー表示し、チェック後に予約ボタンを有効化する。

## 現状

- サイト全体の規約: チェックボックス + リンク（別タブで開く）
- スペース固有規約: ダイアログ表示（スクロール完了検知あり）

## 変更後

- サイト全体の規約: チェックボックス + クリック可能なテキスト → ダイアログ表示
- スクロール完了検知なし（見なくてもチェック可能）
- チェック後に「予約を確定する」ボタンが有効化

```
┌─────────────────────────────────────────────────────────────┐
│  ☐ 利用規約 と プライバシーポリシー に同意します *          │
│      ↑青色リンク    ↑青色リンク                            │

```

## 技術的判断

### TermsAgreementDialogとの違い

| 機能 | TermsAgreementDialog | TermsPreviewDialog |
|------|---------------------|-------------------|
| 用途 | スペース固有規約（必読） | サイト全体規約（任意参照） |
| スクロール検知 | あり | なし |
| 同意ボタン | あり | なし（閉じるのみ） |
| チェックボックス連動 | ダイアログ内 | フォーム側 |

### なぜ別コンポーネントにするか
- 責務が異なる（強制同意 vs 任意プレビュー）
- TermsAgreementDialogを変更すると既存機能に影響
- シンプルに保つ（単一責任原則）
