## 2. タブ構成設計

### 2.1 基本方針

- **役割ベース**でグループ化（利用者の目的に沿った分類）
- **拡張性**を考慮（将来の設定追加に対応）
- **URL永続化**（nuqsでタブ状態をクエリパラメータに反映）
- **コンポーネント分離**（各タブを独立したコンポーネントに）

### 2.2 タブ構成（6タブ）

```
┌────────┬──────────┬───────┬────────┬──────────┬────────────┐
│ 一般   │ 事業者   │  SEO  │ メール │ 予約     │ システム   │
│ General│ Business │  SEO  │ Email  │ Booking  │ System     │
└────────┴──────────┴───────┴────────┴──────────┴────────────┘
```

| タブID     | タブ名   | 含むセクション       | 将来の拡張候補                         |
| ---------- | -------- | -------------------- | -------------------------------------- |
| `general`  | 一般     | 基本情報、連絡先     | テーマ設定、多言語設定                 |
| `business` | 事業者   | 事業者情報、営業時間 | 店舗情報（複数店舗対応）、スタッフ情報 |

### 3.2 技術的詳細

#### URL状態管理（nuqs）

```typescript
// src/app/admin/settings/page.tsx
import { useQueryState } from 'nuqs'

const TABS = ['general', 'business', 'seo', 'email', 'booking', 'system'] as const
type TabId = typeof TABS[number]

export default function SettingsPage() {
  const [activeTab, setActiveTab] = useQueryState('tab', {
    defaultValue: 'general',
    parse: (value) => TABS.includes(value as TabId) ? value as TabId : 'general',
  })

  return (
    <SettingsTabs activeTab={activeTab} onTabChange={setActiveTab}>
      {activeTab === 'general' && <GeneralTab />}
      {activeTab === 'business' && <BusinessTab />}
      {activeTab === 'seo' && <SeoTab />}
      {activeTab === 'email' && <EmailTab />}
      {activeTab === 'booking' && <BookingTab />}
      {activeTab === 'system' && <SystemTab />}
    </SettingsTabs>
  )
}
```
