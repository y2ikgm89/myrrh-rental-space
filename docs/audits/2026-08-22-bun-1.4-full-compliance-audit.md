## 5. 移行中に根治した周辺問題（Bun 1.4 直接ではないが同時期に main 済み）

  Windows の `localhost`→`::1` 解決が stale な wslrelay binding と衝突し pg 単一アドレス
  クライアントだけが ECONNRESET になるクラスの除去。`.env.example` / 既定値 / gate 同期
- `docs/superpowers/plans/2026-07-18-reservation-optimistic-concurrency.md` の
  「Bun 1.3.14」記述は dated plan doc の時点事実であり現状態と矛盾しないため据え置き。
  src 内の `1.3.14` 言及 2 件（PDF spike メモ）も同様
