# Superpowers 成果物

ワークフロー（`CLAUDE.md` の brainstorming / writing-plans）に伴い生成された **plans**（実行計画）と **specs**（設計仕様）を置く。

| ディレクトリ                        | 内容                                        |
| ----------------------------------- | ------------------------------------------- |
| [`plans/`](./plans/)                | 実装順序・チェックリスト付きの計画 Markdown |
| [`specs/`](./specs/)                | plan に対応する設計メモ・アーキ検討         |
| `plans/.archive/`, `specs/.archive` | 完了後にのみ移動。履歴検索用                |

運用ルールは各ディレクトリの `README.md` を参照。
