# 実装品質ルール

## 禁止事項

1. **形骸化実装禁止**
   - 空の関数を残さない
   - TODO コメントだけで実装を終わらせない
   - エラーを無視する実装をしない

2. **過剰な抽象化禁止**
   - 1回しか使わないユーティリティを作らない
   - 将来のための設計をしない

3. **後方互換ハック禁止**
   - 未使用の `_vars` リネーム禁止
   - 型の re-export 禁止
   - `// removed` コメント禁止

## 必須事項

1. **コードを書く前に読む**
   - 関連ファイルを必ず確認
   - 既存パターンに従う

2. **変更は最小限に**
   - 要求された変更のみ実装
   - 「ついでに」の改善をしない

3. **検証を行う**
   - type-check / lint / build を通す
   - 動作確認を行う
