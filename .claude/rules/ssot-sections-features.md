## Feature Module（site-level toggle）

`Settings.featureModules` JSONB を SSoT とする 9 module の declarative composition。OFF module は public route 404 / nav prune / sitemap prune / SectionRenderer skip / cron 早期 return に伝播。

| 定数/変数                                                                                                                                                | 場所                                                                                          | メモ                                                                                                                                                                                               |
| -------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `FEATURE_MODULES_LIST` / `FEATURE_MODULES` / `FeatureModule` / `isFeatureModule()` / `buildInitialFeatureModules()` / `parseDisabledFeatureModulesEnv()` | `@/shared/lib/features/registry`                                                              | 9 module SSoT（spaces / reservation / events / posts / news / faq / access / contact / reviews）+ requires 依存関係。新規 module 追加は registry + Settings JSON + admin UI form schema の同時更新 |
| `isFeatureEnabled(module)` / `requireFeatureEnabled(module)` / `getEnabledFeatures()` / `getFeatureFilterContext()` / `isUrlDisabled(url, routes)`       | `@/shared/lib/features/check`                                                                 | server-only 解決 API。fail-closed（DB key 欠損で OFF）+ 依存伝播。`cache()` request-memo は不使用（`'use cache'` 層で十分、二重メモは test 不互換 silent bug）                                     |
| `Settings.featureModules` (Json)                                                                                                                         | `prisma/schema.prisma`                                                                        | DB SSoT。`Record<FeatureModule, boolean>`。seed の create only 経路で初期化、update では除外して user toggle を保持（→ `prisma-patterns.md §user-mutable JSONB upsert split`）                     |
