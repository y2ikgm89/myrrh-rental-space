# SSOT 定数・シングルトン（日時・メディア・外部連携）

プロジェクト全体で単一定義を厳守する定数・シングルトン一覧。ローカル再定義・重複定義は禁止。

## 日時フォーマット / parser

| 定数/変数                                                                                                                  | 場所                         | メモ                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| -------------------------------------------------------------------------------------------------------------------------- | ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `formatDate` / `formatDateShort` / `formatDateTimeShort` / `formatDateTimeFull`                                            | `@/shared/lib/date-format`   | 公開・管理共通の日時表示 SSoT。コンポーネント内 `Intl.DateTimeFormat` 直接呼び出し禁止                                                                                                                                                                                                                                                                                                                                                                                                |
| `formatDateTimeLocalInJst(date)` / `parseDateTimeLocalAsJst(value)`                                                        | `@/shared/lib/date-format`   | **`<input type="datetime-local">` 用 JST 固定 SSoT**。`new Date(localStr)` / date-fns `format()` はサーバ・ブラウザ tz 依存で 9h ずれる silent bug。**全 admin form の datetime-local は本 SSoT 経由必須**                                                                                                                                                                                                                                                                            |
| `couponFormSchema.validFrom` / `eventFormBaseSchema.startTime` / `barFormSchema.startAt`                                   | `@/shared/lib/validations/*` | datetime-local 値の Zod 契約 SSoT。command 層で必ず `parseDateTimeLocalAsJst()` を通して UTC Date に変換（`new Date(data.x)` 直接禁止）                                                                                                                                                                                                                                                                                                                                               |
| `parseJstDateOnly(value)` / `formatJstDateOnly(date)` / `formatJstDateString(date)` / `calculateDurationHours(start, end)` | `@/shared/lib/date-format`   | **`@db.Date`（日付のみ）列 + machine 形式 + 時間差の JST SSoT**。`@db.Date` は「JST カレンダー日付を UTC 深夜保持」（`parseJstDateOnly` で `${v}T00:00:00.000Z`、`formatJstDateOnly` で逆変換、`BlockedDate.startDate/endDate` が利用）。`formatJstDateString` は任意 datetime → JST `"YYYY-MM-DD"`（`en-CA` Asia/Tokyo、dashboard/cron/availability）。`calculateDurationHours` は `(end-start)/(1000*60*60)`。`datetime-local` 用 `formatDateTimeLocalInJst` を日付のみ列に流用禁止 |

## 外部連携（Calendar / Storage）

| 定数/変数                                                                                                                                                        | 場所                                                                                                                                                                                                         | メモ                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `OUTBOUND_RESERVATION_MARKER` / `OUTBOUND_EVENT_MARKER` / `isAppGeneratedCalendarEvent`                                                                          | `@/shared/lib/calendar-sync/loop-prevention`                                                                                                                                                                 | GCal outbound → inbound ループ防止 SSoT。outbound が description に ID を埋め込み、inbound が `isAppGeneratedCalendarEvent()` で判定してスキップ。literal 重複定義禁止                                                                                                                                                                                                                                                                                                                      |
| `buildReservationCalendar` / `buildEventCalendar` / `buildAddToCalendarUrls` / `buildReservationUid`                                                             | `@/shared/lib/ical`                                                                                                                                                                                          | RFC 5545 準拠 ICS SSoT。直接 `ical()` 呼び出し禁止。ICS DL は `/api/calendar/*` route（`data:` URL は Gmail ブロック）。→ `ical-patterns.md`                                                                                                                                                                                                                                                                                                                                                |
| `STORAGE_PREFIXES` / `StoragePrefix`                                                                                                                             | `@/shared/lib/r2/keys`                                                                                                                                                                                       | 画像ストレージの key prefix SSoT（`spaces` / `posts` / `site` / `media`）。upload / delete の第 2 引数で使用                                                                                                                                                                                                                                                                                                                                                                                |
| `detectMediaMimeFromMagicBytes` / `SUPPORTED_MEDIA_MIME_TYPES` / `MEDIA_MIME_EXTENSIONS` / `deriveMediaTypeFromMime` / `MEDIA_MAX_SIZE_BYTES` / `MAX_FILE_SIZES` | `@/shared/lib/r2/media-magic-bytes`（検出 + MIME 型 + 拡張子、server-only）+ `@/shared/lib/r2/media-type-derivation`（MediaType 派生、client-safe）+ `@/shared/lib/r2/media-size`（サイズ上限、client-safe） | メディア upload の MIME 偽装防止 + MediaType 派生 SSoT。server-side magic-byte から MIME 確定 → `Content-Type` と R2 key 拡張子を `MEDIA_MIME_EXTENSIONS[detected]` から派生（`file.type` / `file.name` 信用禁止）。サイズ上限は `MEDIA_MAX_SIZE_BYTES`（per-MIME canonical）を SSoT とし `MAX_FILE_SIZES`（MediaType 別、`OTHER` のみ 10MB 固定）を派生（client-safe 一本化、二重定義禁止）。per-MIME max size: 画像 5MB / 動画 50MB / 音声 20MB / 文書 10MB。SVG / quicktime は永久対象外 |
