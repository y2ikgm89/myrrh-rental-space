# SSOT 定数・シングルトン（DB・ドメイン）

プロジェクト全体で単一定義を厳守する定数・シングルトン一覧。ローカル再定義・重複定義は禁止。

## DB / Prisma

| 定数/変数                                                                                                    | 場所                                                            | メモ                                                                                                                                                                                                                                                                                                                                                                                        |
| ------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `prisma` / `basePrisma`                                                                                      | `@/shared/db/prisma`                                            | `basePrisma` は Better Auth アダプター専用（`$extends` 前）                                                                                                                                                                                                                                                                                                                                 |
| `Prisma` 型 / Prisma enums（`Role` / `ReservationStatus` 等 34 種）                                          | `@/shared/lib/validations/enums/prisma-types`                   | client-safe gateway。**runtime sentinel（`JsonNull` / `DbNull` / `join` / `sql` / `raw`）は gateway 取得不可** — `shared/db` / `shared/domain` が `@generated/prisma/client` から直接 import                                                                                                                                                                                                |
| `*_STATUS_LABELS` / `AUDIT_ACTION_LABELS` / `PUBLISH_LABELS` / `getPublishLabel()`                           | `enums/helpers`                                                 | 全ステータス enum + boolean publish のラベル SSoT。UI でハードコード禁止                                                                                                                                                                                                                                                                                                                    |
| `RESERVATION_STATUS_ICONS` / `NOTIFICATION_TYPE_ICONS`                                                       | `enums/helpers`                                                 | status / type → curated icon 識別子の固定マッピング SSoT（WCAG 1.4.1 準拠、color 単独は違反）。新 status/type 追加時は `*_LABELS` + `*_BADGE_VARIANTS` + `*_ICONS` を**3 SSoT 同時更新必須**                                                                                                                                                                                                |
| `NOTIFICATION_TYPE` / `isValidNotificationType`                                                              | `enums/helpers`                                                 | DB VARCHAR 管理                                                                                                                                                                                                                                                                                                                                                                             |
| `FaqItem.answer`                                                                                             | `prisma/schema.prisma`                                          | プレーンテキスト単一列（`@db.Text`）。Lexical 本文は Post/News/Terms/Section のみ                                                                                                                                                                                                                                                                                                           |
| `FAQ_STALE_DAYS` (180) / `FAQ_RECENT_DAYS` (7) / `FAQ_LOW_RATED_MIN_NOT_HELPFUL` (1) / `getFaqHealthSummary` | `@/shared/domain/faq/constants` + `@/shared/domain/faq/queries` | FAQ コンテンツ健全性しきい値 SSoT（client-safe）。管理 quickFilter（recent/stale/low-rated）+ ランディング健全性チップ + 鮮度 cron（`faq-stale-check`）で共有。**`stale` の日数は cron 通知と一致必須**（通知 → 絞り込み動線がぶれない）。`low-rated` は Prisma が列間比較不可のため `notHelpfulCount >= 1`（Intercom negative reactions 思想）。cron / queries / UI での再ハードコード禁止 |
| `BLOCKED_DATE_SCOPE` / `BLOCKED_DATE_TYPE` / `isValid*` / `getValid*` / `*_LABELS`                           | `enums/helpers`                                                 | DB VARCHAR 管理（Prisma enum ではない、`NOTIFICATION_TYPE` 同方式）。`BlockedDate.scope`（SPACE/LOCATION/GLOBAL）/ `type`（HOLIDAY/MAINTENANCE/EMERGENCY/OTHER）の型ガード SSoT。scope discriminated union は Zod `superRefine` + DB CHECK 制約で二重防御                                                                                                                                   |

| `EventTicketWritableFields` / `EventTicketInput` / `EventTicketSummary` / `EventTicketOption` / `createDefaultTicket` | `@/shared/domain/events/ticket-types`                                                                     | EventTicket チケット種別の型 SSoT（4 レイヤー型、Prisma `Pick` 派生）。各レイヤーでの重複型定義禁止。`_key` フィールドは React reconciliation 用 UI 専用（Zod strip 破棄）                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| Event / Space の dedicated curated related-articles section — **不採用 (anti-pattern)**                               | n/a                                                                                                       | 業界調査 0/11 採用率（event/space は conversion 目的で curated section は離脱誘発）。代替は Lexical Bookmark Node + `RelatedEvents`。`EventRelatedPost` 等の pivot table 復活禁止                                                                                                                                                                                                                                                                                                                                                                                                                                                            |

| Settings 連絡先住所（派生関数 SSoT）                                                                                  | 4 派生並立                                                                                                | **`Settings.address` カラムは廃止済**。表示用住所は構造化フィールド（`postalCode` / `prefecture` / `city` 等）が SSoT。`Settings.address` 再導入禁止                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| Location 連絡先・アクセス・駐車場（per-location SSoT）                                                                | `Location` モデル                                                                                         | **`Settings.accessInfo` / `Settings.parkingInfo` は廃止済**。アクセス情報は `Location.accessLines Jsonb`（`string[]`）、駐車場は `Location.parkingInfo String?`。Settings 側に同名フィールドを復活させない                                                                                                                                                                                                                                                                                                                                                                                                                                   |

| `TermsDocument` / `TermsAgreement` / `recordTermsAgreementsCommand`                                                   | `prisma/schema.prisma` + `@/shared/domain/terms` + `@/shared/lib/validations/terms`                       | 規約管理 SSoT。`TermsDocument`（最新版直接保存、`isPublished` boolean）+ `TermsAgreement`（同意時 `contentSnapshot` + sha256 hash で証跡化）。`recordTermsAgreementsCommand` は `fireAndForget` で非ブロッキング保存                                                                                                                                                                                                                                                                                                                                                                                                                         |

| `getPagePreviewHref` / `getPostPreviewHref` / `getNewsPreviewHref` / `getPublicPageHref` / `normalizePreviewPathname` | `@/shared/lib/preview-routes`                                                                             | 管理画面 → preview / 公開ページへの URL 生成 + nav active 正規化 SSoT。`/preview/pages/<slug>` 等のリテラル直書き禁止                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| BlockedDate（臨時休業 / 急な休み）model + domain + 予約判定 + 管理 UI                                                 | `prisma/schema.prisma` + `@/shared/domain/blocked-dates/**` + `@/shared/domain/reservations/availability` | 日付範囲ベースの休業 SSoT。`scope`/`type` は VARCHAR + `enums/helpers` 型ガード、`startDate`/`endDate` は `@db.Date`、`reason` は plain text。**予約判定**: `isDateBlocked` が GLOBAL/LOCATION/SPACE の 3 階層 additive cascade（OR、override なし）、`ensureDateNotBlocked` が公開予約で `DomainError("CONFLICT")` 物理防止（管理予約は override 許容）、`getBlockedDateRangesForSpace` が公開カレンダー grey-out 用。**管理 UI**: `BlockedDatesField`（scope-generic）を space/location 編集タブ + `/admin/settings/holidays` の 3 scope で共有。**禁止**: /news 等への auto 転載（operational data → content sync は drift anti-pattern） |
| 休業の 3 系統（曜日定休 / 毎月第N曜日 / 不定期期間）の使い分け                                                        | `businessHours` + `BlockedDate`                                                                           | **新休業要件の判断軸**: ① 曜日定休（週次）= `Settings.businessHours.{day}.isOpen` ② 毎月第N曜日 = `businessHours.monthlyClosures: [{ weekday, week }]`（JSONB、`.optional()` で migration 不要） ③ 不定期期間（年末年始/設備点検/災害）= `BlockedDate`（`@db.Date` 範囲、3 階層 scope）。**繰り返し定休は businessHours、不定期期間は BlockedDate**（混同禁止）。`isMonthlyClosureDate` が slot 生成 / 公開 calendar grey-out で共用。曜日反復は `WeekdayKey` 型（`monthlyClosures` 混入で `keyof BusinessHours` が曜日キー以外を含むため）                                                                                                  |
