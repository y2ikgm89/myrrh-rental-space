# /review-cc-work - Claude Code の実装をレビュー

Claude Code が完了報告した実装をレビューします。

## 実行内容

1. **Plans.md を確認** - `cc:完了` タスクを抽出
2. **変更差分を表示** - Git diff で確認
3. **レビューポイントを提示** - チェック項目
4. **承認 or フィードバック**

## 使い方

```
/review-cc-work
```

または

「Claude の実装を確認」「レビューして」

## 出力例

```
🔍 レビュー対象
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📋 完了タスク:
- ユーザー登録フォームコンポーネント作成
- Server Action で登録処理実装

📁 変更ファイル:
- src/app/auth/register/page.tsx（+45行）
- src/actions/auth.ts（+67行）
- src/lib/validations/auth.ts（+23行）

✅ チェック項目:
- [ ] 要件を満たしているか
- [ ] エラーハンドリングは適切か
- [ ] セキュリティ（入力検証、CSRF）
- [ ] テストは追加されているか

💡 アクション:
- 承認: 「承認」「OK」「LGTM」
- 修正依頼: 「〇〇を修正して」
```

## 承認後

承認すると Plans.md のマーカーが `pm:確認済` に更新されます。
