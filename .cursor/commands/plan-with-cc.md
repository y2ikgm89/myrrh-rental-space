# /plan-with-cc - Claude Code で計画作成

Claude Code を使って実装計画を作成し、Plans.md に追加します。

## 実行内容

1. **要件をヒアリング** - 何を作りたいか
2. **技術調査** - 必要な技術・ライブラリ
3. **タスク分解** - 実装ステップを洗い出し
4. **Plans.md に追加** - `pm:依頼中` マーカーで

## 使い方

```
/plan-with-cc ユーザー登録機能を作りたい
```

または

「〇〇の計画を立てて」「〇〇を実装する方法を考えて」

## 出力例

```
📋 計画作成完了 - ユーザー登録機能
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## タスク一覧

1. `pm:依頼中` Prisma スキーマに User モデル追加
2. `pm:依頼中` 登録フォームコンポーネント作成
3. `pm:依頼中` Server Action で登録処理実装
4. `pm:依頼中` バリデーション追加（Zod）
5. `pm:依頼中` テスト作成

Plans.md に追加しました。
`/handoff-to-claude` で Claude Code に依頼できます。
```
