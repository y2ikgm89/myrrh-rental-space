# /start-session - セッション開始

セッション開始時に状況を把握し、次のアクションを提案します。

## 実行内容

1. **Plans.md を確認** - 現在のタスク状況
2. **Git 状態を確認** - 未コミット変更、ブランチ
3. **前回の作業を把握** - WIP タスク、ブロッカー
4. **次のアクションを提案**

## 使い方

```
/start-session
```

または

「今日の作業を始めたい」「続きをやりたい」

## 出力例

```
📊 セッション開始 - myrrh-rental-space
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📋 Plans.md 状況:
- WIP: 1件（ユーザー認証機能）
- TODO: 3件
- 完了: 5件

🔀 Git 状態:
- ブランチ: feature/auth
- 未コミット: 2ファイル

💡 推奨アクション:
1. WIP タスク「ユーザー認証機能」を継続
2. 未コミット変更をコミット
```
